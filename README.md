# Purtidy Workspace

Purtidy 商品审核与素材工作台的静态网站发布仓库。

[打开工作台](https://jiyr0119.github.io/purtidy-workspace/)

## 功能

- 按日期或关键词浏览商品，查看完整商品图和英文详情图。
- 对照 1688 货源、英文 Listing，逐张或打包下载当前成品素材。
- 本地保存审核意见，导出 JSON，试算商品贡献与物流成本。
- 适配手机与电脑，提供登录入口和退出功能。

## 更新方式

本仓库由私有工作库的发布流程自动同步，只保留当前网站使用的成品页面和图片。研究过程、原始工作文件、账号配置与历史草稿保留在私有库。

推送后，GitHub Actions 自动部署 GitHub Pages。下载包由浏览器按需生成，整批下载建议在电脑操作。

## 使用说明

审核意见与成本输入仅保存在当前浏览器，不会在家庭成员或设备之间自动同步。请使用页面的导出按钮保存记录。

前端登录仅用于减少随意浏览，不是服务端访问控制。本仓库及静态资源公开可访问。请勿在本仓库保存敏感资料或密码。

商品图片和品牌素材用于 Purtidy 商品审核与运营；公开可访问不代表授予转载或商业使用许可。
